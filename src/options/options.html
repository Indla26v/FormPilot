How to Set Environment Variable (OLLAMA_ORIGINS = *):
  1. Press Win + R, type sysdm.cpl, and press Enter (or search for "Edit the system environment variables" in the Start Menu).
  2. Go to the Advanced tab and click Environment Variables... at the bottom.
  3. Under User variables (or System variables), click New...
  4. Set Variable name: OLLAMA_ORIGINS and Variable value: *
  5. Click OK on all dialogs, right-click the Ollama icon in the Windows taskbar tray & select Quit Ollama, then restart Ollama.
PowerShell 1-Click Command (Run in Terminal): [System.Environment]::SetEnvironmentVariable('OLLAMA_ORIGINS', '*', 'User')
  1. Open Terminal and run the command below to set the variable for the Ollama macOS GUI app and shell profile.
  2. Quit Ollama from the top menu bar icon, and relaunch it from Applications.
Terminal 1-Click Command (Run in Terminal): launchctl setenv OLLAMA_ORIGINS "*" && echo 'export OLLAMA_ORIGINS="*"' >> ~/.zshrc
  1. If running Ollama as a systemd service, edit the service environment overrides with sudo systemctl edit ollama.service.
  2. In the editor, add the [Service] section with Environment="OLLAMA_ORIGINS=*".
  3. Reload systemd and restart the service with the commands below.
Terminal Commands (Run in Terminal): sudo systemctl daemon-reload && sudo systemctl restart ollama
